# Attribution

## Course inspiration

This project was inspired by the material and public assignments from WPI’s RBE/CS 549: Computer Vision course, taught by Prof. Nitin J. Sanket. I used those ideas to build an ORB-based system that tracks camera motion and builds a sparse 3D map, then tested it on KITTI.

Public course material: https://rbe549.github.io/.

This is an independently scoped monocular implementation, not a claim of an official course submission or a complete implementation of the course's visual-inertial or NeRF assignments.

## KITTI data and derived media

The images, calibration, source timestamps, and ground-truth poses are from the KITTI Vision Benchmark Suite by Andreas Geiger, Philip Lenz, and Raquel Urtasun. Dataset: https://www.cvlibs.net/datasets/kitti/.

KITTI's published license is Creative Commons Attribution-NonCommercial-ShareAlike 3.0: https://creativecommons.org/licenses/by-nc-sa/3.0/.

Project visualizations add feature overlays, camera trajectories, maps, and explanatory labels to KITTI imagery.
